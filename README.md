# Student Management System

A Java-based web application built from the ground up to learn
Java web development, JDBC, MySQL, CRUD operations, and layered architecture.

## Technology Stack

- Java 21
- Maven
- Apache Tomcat
- JDBC
- MySQL
- HTML/CSS
- Git/GitHub

## Learning Goal

The application will first be implemented using Java web technologies
without Spring Boot.

After understanding the underlying concepts, the project will be
used as a foundation for learning Spring Boot.
